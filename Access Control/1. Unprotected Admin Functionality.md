
## 1. Unprotected Admin Functionality

**Objective:**  
Find the admin panel and delete user `carlos`.

**Steps:**

- Checked `robots.txt` for hidden paths.
- Found:

```bash
Disallow: /administration-panel
```

- Navigated to `/administration-panel`.
- Accessed admin functionality.
- Deleted user `carlos`.

**Conclusion:**

- This is a **Vertical Privilege Escalation** vulnerability.
