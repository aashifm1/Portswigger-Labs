## 5. User ID Controlled by Request Parameter with Password Disclosure

**Objective:**  
Obtain administrator password and delete user `carlos`.

**Credentials:**  
`wiener:peter`

**Steps:**

- Logged in as `wiener`.
- Navigated to:

```bash
/my-account?id=wiener
```

- Observed password update functionality.
- Password not visible in UI but present in page source.

### Exploit:

- Visited:

```bash
/my-account?id=administrator
```

- Viewed page source.
- Found admin password in plaintext:

```bash
tue22l1rqg5y6i4bgo78
```

### Final Steps:

- Logged in as `administrator`.
- Accessed admin panel.
- Deleted user `carlos`.
