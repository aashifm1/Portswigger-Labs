## 3. User Role Controlled by Request Parameter

**Objective:**  
Gain admin access and delete user `carlos`.

**Credentials:**  
`wiener:peter`

**Steps:**

- Logged in as `wiener`.
- Tried accessing admin panel → received `401 Unauthorized`.

<img width="918" height="400" alt="image1" src="https://github.com/user-attachments/assets/98133d98-f386-44dd-a388-d574ee4e9cc1" />

- Intercepted request in Burp Suite.
- Found parameter:

```bash
Admin=false
```

- Modified it to:

<img width="800" height="500" alt="image2" src="https://github.com/user-attachments/assets/fbaf918d-6b75-469c-9a2c-752043369217" />


```bash
Admin=true
```

- Forwarded the request.

**Result:**

- Gained access to admin functionality.

<img width="983" height="491" alt="image3" src="https://github.com/user-attachments/assets/89d2e95b-c868-4e52-967d-e553973b9610" />

- Intercepted delete request and again changed:

```bash
Admin=true
```

- Successfully deleted user `carlos`.
